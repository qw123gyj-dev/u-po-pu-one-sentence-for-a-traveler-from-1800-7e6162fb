# One Sentence for a Traveler from 1800

How do you explain the modern internet to someone who arrived this morning from the year 1800, in a single sentence and without a single word coined after their time? This program answers with pictures they already know — libraries, printing presses, post houses, letters, and thin wires — then validates the sentence against every rule of the bounty before writing it to `entry.txt`.

> Imagine every library, printing press, and post house joined by thin wires, so a letter you write at home reaches any town crier, scholar, or friend across the world in a breath.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/traveler-out node main.ts
```
